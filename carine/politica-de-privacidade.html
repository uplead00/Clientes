Política de Privacidade

Esta página descreve quais dados este site coleta, como eles são usados e quais são os seus direitos segundo a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Quem é o responsável

Carine Hernandes, atuando sob a marca Outliers, é a responsável pelo tratamento dos dados enviados por meio deste site. O contato para qualquer assunto relacionado a esta política é o WhatsApp (41) 99800-3873.

Quais dados são coletados

O formulário de contato deste site pede apenas dois campos, ambos preenchidos por você:

  • o nome pelo qual você prefere ser chamado;
  • a descrição do seu desafio ou necessidade financeira.

O site não usa cookies, não possui ferramentas de análise de audiência e não possui pixels de rastreamento. Nenhuma informação de navegação é registrada para fins de publicidade ou perfilamento.

Como esses dados são enviados

Este site não possui banco de dados nem servidor próprio de recebimento. Ao enviar o formulário, os dois campos são montados em uma mensagem de texto e o seu navegador é redirecionado para o WhatsApp, já com essa mensagem escrita. O envio só acontece quando você aperta enviar dentro do próprio WhatsApp.

Ou seja: os dados não ficam armazenados neste site em momento algum. A partir do envio, a conversa passa a existir apenas no WhatsApp, cujo tratamento de dados é regido pela política de privacidade da Meta.

Para que os dados são usados

Exclusivamente para responder ao seu contato e conduzir a reunião de diagnóstico. Os dados não são vendidos, alugados nem compartilhados com terceiros para fins comerciais.

Serviços de terceiros usados nesta página

Para funcionar, o site carrega um único recurso externo. Por ser uma requisição feita pelo seu navegador, esse serviço recebe o seu endereço IP:

  • Google Fonts (fonts.googleapis.com e fonts.gstatic.com), que fornece as fontes tipográficas.

Ao clicar nos links de WhatsApp, Instagram ou LinkedIn, você é levado para fora deste site e passa a estar sujeito às políticas de privacidade dessas plataformas.

Por quanto tempo os dados são guardados

Como o site não armazena nada, o prazo se refere apenas à conversa iniciada no WhatsApp, mantida enquanto durar o relacionamento de atendimento ou até que você peça a exclusão.

Seus direitos

A LGPD garante a você, a qualquer momento, o direito de:

  • confirmar se existe tratamento dos seus dados e acessá-los;
  • corrigir dados incompletos, inexatos ou desatualizados;
  • solicitar a eliminação dos dados;
  • revogar o consentimento;
  • obter informação sobre com quem os dados foram compartilhados.

Para exercer qualquer um desses direitos, basta enviar a solicitação pelo WhatsApp (41) 99800-3873.

Segurança

Este site é servido exclusivamente por conexão criptografada (HTTPS) e não expõe nenhum formulário que transmita dados para servidores próprios.

Alterações nesta política

Caso este site passe a usar cookies, ferramentas de análise ou qualquer forma de armazenamento de dados, esta página será atualizada antes da mudança entrar no ar.
